# Browser Chat

通过专用 Chrome 或 Edge 操作 ChatGPT 网页，并将文字回答发送到 QQ 的 AstrBot 插件。

## 功能

- 支持 QQ 群聊和私聊，支持直接引用消息中的文字。
- 每次提问使用独立网页会话，默认在完成后删除，也可配置保留。
- 优先使用合并转发发送回答，长答案自动截断、分段。
- 提供群与用户白名单、有界排队、超时和任务取消。
- 网页或发送故障可通过来源机器人私信通知管理员。

仅支持文字；不处理图片、附件或嵌套转发，不沿用上一条问题的会话上下文。

## 安装

需要已运行的 AstrBot、QQ OneBot v11 连接（如 NapCat），以及已安装的 Chrome 或 Microsoft Edge。浏览器以可见窗口运行，部署环境需要可用的桌面会话。

1. 将插件放入 `AstrBot/data/plugins/astrbot_plugin_browser_chat`。
2. 使用**实际运行 AstrBot 的 Python 解释器**安装依赖：

   ```powershell
   & '<AstrBot 的 python.exe>' -m pip install -r '<插件目录>\requirements.txt'
   ```

   Python 环境应满足所安装 AstrBot 的要求。插件使用系统浏览器，无需下载 Playwright 自带浏览器；不会在导入时自动安装依赖。

3. 在 AstrBot 管理页填写插件配置，尤其是 `admin_ids` 和使用白名单，再加载插件。
4. 按下一节完成手动登录和账号设置，然后恢复接单。

更新插件时保留宿主中的插件配置和 `data/plugin_data/astrbot_plugin_browser_chat/`，其中包含登录资料及会话归属记录。

## 首次登录与恢复

插件启动后默认暂停接单，并打开专用浏览器。

1. 在该窗口访问 `https://chatgpt.com/`，手动登录。
2. 在 ChatGPT 账号设置中实际关闭记忆、引用聊天历史及自定义指令。新建会话不能代替这些设置。
3. 由插件管理员发送：

   ```text
   /ask resume 已核验
   ```

4. 收到已恢复接单的回执后，开始提问。

`已核验` 是管理员的人工确认，插件不会代为检查或修改账号设置。更换账号或重新登录后，应重新核验。验证码必须手动处理；插件不会绕过验证码、地区限制或限流。

### 选择 Edge

在插件配置中设置：

```json
{
  "browser_channel": "msedge",
  "browser_profile_name": ""
}
```

修改后重载本插件，再在新打开的专用 Edge 中登录。Chrome 和 Edge 默认使用不同资料目录，切换浏览器不会自动迁移登录状态。

插件启动并管理自己的专用浏览器，不能直接接管日常已经打开的浏览器。不要将个人浏览器资料目录复制进插件，也不要同时启动多个进程占用同一专用目录。

## 使用命令

下面使用 `/` 表示命令前缀。请按 AstrBot 实际配置替换；例如唤醒前缀为 `#` 时，发送 `#ask ai 你好`。

| 命令 | 用途 | 权限 |
| --- | --- | --- |
| `/ask ai 问题` | 提交一次文字提问 | 满足启用的白名单 |
| `/ask cancel` | 取消自己的未完成任务 | 任务本人 |
| `/ask status` | 查看运行状态、执行数、等待数和暂停原因 | 管理员 |
| `/ask resume` | 重新检查网页及残留清理状态 | 管理员 |
| `/ask resume 已核验` | 人工核验账号设置后检查并恢复接单 | 管理员 |

### 普通提问

```text
/ask ai 请用三句话解释什么是递归。
```

### 引用提问

在 QQ 中引用一条文字消息，再发送：

```text
/ask ai 请总结引用内容。
```

插件将直接引用中的文字与当前问题一起提交。只发送 `/ask ai` 且带有文字引用时，会将引用文字作为问题；没有可用文字或引用读取失败时会提示错误。

### 排队与取消

默认同时执行 1 个任务，另有 5 个等待位置。同一用户跨群聊和私聊最多一个未完成任务；排队已满或已有任务时会拒绝新的请求。

取消后会等待必要的资源清理。已提交给 QQ 或发送结果未知的消息不会被撤回，也不会因取消重新发送。

## 配置

通过 AstrBot 插件配置页修改，重载本插件后生效。已接纳任务使用原配置快照，包括白名单、长度限制、保留策略及通知模板。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `restrict_groups` | `false` | 是否启用群白名单 |
| `allowed_groups` | `[]` | 允许的群号，填写字符串 ID；启用限制但列表为空时拒绝所有群 |
| `restrict_users` | `false` | 是否启用用户白名单 |
| `allowed_users` | `[]` | 允许的用户 QQ，填写字符串 ID；启用限制但列表为空时拒绝所有用户 |
| `max_concurrency` | `1` | 同时执行的任务数，必须为正整数 |
| `queue_capacity` | `5` | 等待位置数量；`0` 表示不排队 |
| `execution_timeout_seconds` | `180` | 单次网页生成超时，单位秒，不含排队、发送与清理时间 |
| `queue_timeout_seconds` | `600` | 排队超时，单位秒 |
| `max_input_chars` | `12000` | 引用与当前问题合并后的字符上限，超限拒绝 |
| `max_reply_chars` | `12000` | 答案总字符上限，包含截断提示 |
| `forward_node_chars` | `1500` | 单个转发节点的字符上限，不能超过答案总上限 |
| `keep_conversations` | `false` | 是否保留插件创建的网页会话；默认删除 |
| `admin_ids` | `[]` | 接收故障通知并可执行管理命令的 QQ 字符串 ID 列表 |
| `user_failure_template` | `任务 {task_id} 失败：{reason}。` | 发送给提问用户的失败提示 |
| `admin_failure_template` | 见下方 | 管理员故障通知模板 |
| `browser_channel` | `chrome` | `chrome` 或 `msedge`，使用系统已安装的浏览器 |
| `browser_profile_name` | 空字符串 | 专用资料目录名称；留空使用所选浏览器的默认目录 |

群与用户限制互相独立：同时启用时，群聊必须同时满足两类白名单；私聊只检查用户白名单。`admin_ids` 不会绕过提问白名单，宿主超级管理员也可执行管理命令。AstrBot 自身的唤醒、白名单和会话插件开关同样有效。

### 专用资料与会话保留

专用资料位于宿主 `data/plugin_data/astrbot_plugin_browser_chat/`：

- Chrome 默认目录：`browser_profile/`。
- Edge 默认目录：`browser_profile_msedge/`。
- 自定义名称仅允许 1—64 位英文字母、数字、下划线或短横线，不接受路径及 Windows 保留名称。

插件为不同资料目录分别保存会话归属记录，只清理明确由自己创建的会话，不遍历删除账号历史。保留策略在任务接纳时固定；修改 `keep_conversations` 不会改变旧任务的策略。

浏览器登录资料、会话归属文件、Cookie、日志及截图应保留在本地，不上传到仓库。不要随意删除会话归属文件，否则插件将无法可靠追踪历史任务的清理结果。

### 失败提示与管理员通知

管理员默认模板：

```text
[BrowserChat] {category}
任务：{task_id}
来源：{source}
时间：{time}
原因：{reason}
次数：{count}
```

两个模板均只允许 `{task_id}`、`{reason}`、`{category}`、`{source}`、`{time}`、`{count}`，不支持属性访问、下标或表达式。

通知由任务来源机器人发送，可配置多个管理员；请确保该机器人能够私信管理员。相同来源平台、浏览器范围和故障类别在 300 秒内合并：首次立即通知，后续故障累计后汇总。默认通知不包含问题与回答正文；通知发送失败只记录日志。

## 常见问题

**提示服务已暂停**

先由管理员执行 `/ask status` 查看原因。检查插件配置、依赖、专用浏览器登录状态及账号设置；处理后执行 `/ask resume 已核验`。遇到限流或验证码时先手动处理，不要反复提交问题。

**已经登录，仍无法恢复**

确认登录的是插件打开的专用窗口。切换浏览器或资料目录后需要在对应窗口重新登录。若页面仍被判定为不可用，检查宿主日志；网页布局或语言变化可能需要更新插件。

**合并转发失败或只收到部分内容**

平台明确拒绝合并转发时，插件会有限降级为普通分段消息。请求超时或结果未知时不会重复发送全文；普通分段部分成功时不会重发已确认发送的段。

**回答已收到，却提示会话清理失败**

回答投递与网页清理分别记录，清理失败不会重发答案。请检查专用浏览器和日志，人工核实自建会话的清理结果后再恢复，不要删除归属文件或反复重发原问题。

**重载插件有什么影响**

本插件停止接单，取消并等待自身任务清理，关闭专用浏览器后重新初始化；需要重新执行恢复检查。已提交的 QQ 消息不会撤回。只需重载本插件，无需重启整个 AstrBot。

## 使用限制

- 依赖 ChatGPT 网页和账号的实际可用性，不保证网站额度或页面布局长期不变。
- 默认建议保持单任务执行；提高并发前，应确认独立会话、回答及清理在当前环境中工作正常。
- 问题提交结果未知时不会自动重试；请先检查网页会话，避免重复提问。
- 每条问题使用独立会话，但账号级设置仍需人工管理。
