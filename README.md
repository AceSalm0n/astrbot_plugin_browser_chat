# astrbot_plugin_browser_chat

计划通过专用浏览器操作 ChatGPT 网页，将文字回答返回 QQ 的 AstrBot 插件。后续考虑 Gemini 和 DeepSeek 适配。

**当前状态：仅初始化仓库与开发规范，尚未实现插件功能。开发方案等待 Astra 复核，暂不可安装使用，也尚未提交 AstrBot 插件市场。**

开发前阅读 [AGENTS.md](AGENTS.md)。插件入口、元数据、配置和依赖将在方案复核并获准实施后添加。
